# Demo Barbería Miguel

Landing conceptual para **Barbería Miguel**, desarrollada por Ross Digital Studio.

## Enfoque
- estética vintage / clásica / rock & roll
- tonos negro, crema, madera y cobre
- responsive mobile / tablet / desktop
- animaciones al hacer scroll
- precios, servicios, trabajos, horarios y contacto
- CTA a Instagram como canal público disponible
- barra fija inferior en mobile

## Datos públicos utilizados
- Wilde, Buenos Aires
- Lunes a sábados de 10:00 a 20:00
- Corte: $15.000
- Corte + barba: $18.000
- Corte jubilados: $8.000
- Servicios publicados: caballeros, niños, degradés, clásicos, color, mechas, barba, cejas/orejas, líneas y diseños
- Instagram: @miguel.barber_ok

## Nota
No se incluyó una dirección exacta porque no aparece claramente en el material compartido. Las imágenes son ilustrativas y de stock. La demo incluye `noindex,nofollow` y no representa una web oficial del negocio.
